# Les centres médicaux au Luxembourg — V1

Carte interactive construite avec Leaflet, Geoportail Luxembourg / ACT, données Doctena 2026 (collecte partielle) et statistiques STATEC.

## Publication GitHub Pages
- `index.html` à la racine
- `assets/` pour le logo et le style
- `data/` pour les données JSON

La collecte Doctena 2026 n'est pas exhaustive. Elle pourra être remplacée ultérieurement par une collecte nationale plus complète sans modifier l'architecture de la carte.
